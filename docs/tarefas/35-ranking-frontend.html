O cálculo de nível e a ordenação já vêm prontos da API Repare que tanto a ordenação (.sort()) quanto o cálculo de nível (getLevel()) que existiam no frontend já foram implementados no backend, na tarefa 17 — o RankingController já devolve a lista ordenada e com level calculado. Isso é bom: a regra de negócio mora num lugar só (o backend), e qualquer cliente futuro (um app mobile, por exemplo) recebe o mesmo cálculo sem precisar reimplementá-lo.

A API não sabe, por padrão, quem é "o usuário logado vendo a tela" dentro da lista geral — isso é uma comparação que faz mais sentido no frontend.
