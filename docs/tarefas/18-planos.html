Tarefa 18 Pessoa C Pendente

Planos (Free/Pro)

Mesma receita de migration + model + seeder + controller + rota que você já fez várias vezes. É um bom módulo pra adiantar enquanto espera a tabela attempts ficar pronta (ele não depende de Practice nem de Ranking, só de users).

Passo a passo (resumido)

1

Migration + Model + Seeder

docker compose exec backend php artisan make:model Plan -m

Colunas: name, price (decimal), description, features ($table->json('features') — uma lista de funcionalidades incluídas), billing_period (string: "monthly" ou "lifetime").

No seeder, crie os dois planos que já existem no frontend: Free (R$ 0) e Pro (R$ 4,99, vitalício).

2

Controller e rota

public function index()
{
    return Plan::all();
}
Route::get('/plans', [PlanController::class, 'index']);

Pública — qualquer um pode ver os planos disponíveis antes de se cadastrar.
