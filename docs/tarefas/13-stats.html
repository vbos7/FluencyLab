Estatísticas do usuário

Seu módulo é focado em consultas SQL de agregação — somar e contar dados que já existem no banco. Não tem lógica de negócio complexa, mas é onde o SQL realmente brilha. Leia a página de Fundamentos antes, especialmente a parte de PDO.

Funções SQL novas: COUNT e SUM

-- Conta quantas linhas existem para user_id = 5
SELECT COUNT(*) FROM attempts WHERE user_id = 5

-- Soma a coluna xp_earned de todas as tentativas desse usuário
SELECT SUM(xp_earned) FROM attempts WHERE user_id = 5

-- Conta apenas as corretas
SELECT COUNT(*) FROM attempts WHERE user_id = 5 AND is_correct = 1

Podemos fazer tudo numa query só com CASE WHEN:

SELECT
    COUNT(*) AS totalPracticed,
    SUM(CASE WHEN is_correct = 1 THEN 1 ELSE 0 END) AS totalCorrect,
    COALESCE(SUM(xp_earned), 0) AS userXp
FROM attempts
WHERE user_id = ?

COALESCE(SUM(...), 0): se não houver nenhuma tentativa, SUM() retorna NULL. O COALESCE substitui NULL por 0.

O arquivo

backend/api/user/stats.php
<?php
require_once __DIR__ . '/../cors.php';
require_once __DIR__ . '/../db.php';

if ($_SERVER['REQUEST_METHOD'] !== 'GET') { json_out(['error' => 'Método não permitido'], 405); exit; }
if (!isset($_SESSION['user_id']))          { json_out(['error' => 'Não autenticado'], 401);      exit; }

$stmt = $pdo->prepare("
    SELECT
        COUNT(*) AS totalPracticed,
        SUM(CASE WHEN is_correct = 1 THEN 1 ELSE 0 END) AS totalCorrect,
        COALESCE(SUM(xp_earned), 0) AS userXp
    FROM attempts WHERE user_id = ?
");
$stmt->execute([$_SESSION['user_id']]);
$row = $stmt->fetch();

json_out([
    'totalPracticed' => (int) $row['totalPracticed'],
    'totalCorrect'   => (int) $row['totalCorrect'],
    'userXp'         => (int) $row['userXp'],
]);
