Tarefa 13 Pessoa C Pendente

Estatísticas do usuário

Primeira tarefa do seu módulo. Antes de começar, vale entender uma decisão importante: não existe uma tabela progress. Os números que o frontend mostra (total praticado, total de acertos, XP) são calculados na hora, a partir da tabela attempts que a Pessoa B criou na tarefa 12. Se essa tarefa ainda não foi feita pelo seu colega, fale com ele antes de continuar — você depende da tabela attempts existir.

O que você vai aprender

  • Como fazer contagens e somas com Eloquent (count(), sum()) em vez de SELECT COUNT(*) na mão.
  • Por que às vezes é melhor calcular na hora do que guardar um número pronto numa coluna.

Por que calcular em vez de guardar pronto?

Você poderia ter uma coluna users.total_xp que vai sendo somada a cada tentativa. O problema: agora existem duas fontes da verdade (a soma das tentativas, e o número guardado) que podem ficar dessincronizadas se algum bug acontecer no meio do caminho. Calculando direto da tabela attempts toda vez, o número está sempre certo — o custo é uma query um pouco mais pesada, o que pra esse projeto não é problema.

Passo a passo

1

Controller

docker compose exec backend php artisan make:controller StatsController
backend/app/Http/Controllers/StatsController.php
use App\Models\Attempt;
use Illuminate\Http\Request;

public function stats(Request $request)
{
    $userId = $request->user()->id;

    $attempts = Attempt::where('user_id', $userId);

    return response()->json([
        'totalPracticed' => (clone $attempts)->count(),
        'totalCorrect' => (clone $attempts)->where('is_correct', true)->count(),
        'userXp' => (clone $attempts)->sum('xp_earned'),
    ]);
}
Por que (clone $attempts)? Em Eloquent, uma "query" ($attempts aqui) vai acumulando condições conforme você encadeia métodos — ela não "reseta" sozinha entre uma chamada e outra. Se você reaproveitar a mesma variável pra três contagens diferentes sem clonar, a segunda chamada herda os filtros da primeira (e dá resultado errado). clone garante que cada contagem comece do zero, só com o filtro de user_id que você quer manter.

Rota

backend/routes/api.php
use App\Http\Controllers\StatsController;

Route::middleware('auth:sanctum')->group(function () {
    // ...
    Route::get('/user/stats', [StatsController::class, 'stats']);
});
