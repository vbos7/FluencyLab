Upload de avatar

Primeira tarefa do guia que lida com upload de arquivo (até agora, tudo foi texto/JSON). Em PHP puro isso seria ler $_FILES['avatar'] e mover o arquivo com move_uploaded_file() — o Laravel embrulha isso numa API um pouco mais segura e conveniente.

Passo a passo

1

Coluna pra guardar o caminho do arquivo

docker compose exec backend php artisan make:migration add_avatar_path_to_users_table --table=users
$table->string('avatar_path')->nullable()->after('role');
2

Controller

// ProfileController.php
public function uploadAvatar(Request $request)
{
    $request->validate([
        'avatar' => ['required', 'image', 'max:2048'], // até 2MB
    ]);

    // store() salva o arquivo em storage/app/public/avatars
    // e devolve o caminho relativo, pronto pra guardar no banco
    $path = $request->file('avatar')->store('avatars', 'public');

    $request->user()->update(['avatar_path' => $path]);

    return response()->json([
        'avatar_url' => asset('storage/' . $path),
    ]);
}
Link simbólico do storage Pra essa URL funcionar, o Laravel precisa de um link simbólico ligando public/storage a storage/app/public. Rode uma vez: docker compose exec backend php artisan storage:link.
3

Rota

Route::post('/profile/avatar', [ProfileController::class, 'uploadAvatar']);

(dentro do grupo auth:sanctum)
