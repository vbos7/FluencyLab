Fundamentos — O que é uma API em PHP puro

Você já sabe receber dados de um formulário HTML com $_POST e devolver HTML de volta. Uma API (Application Programming Interface) faz exatamente a mesma coisa — só que em vez de devolver HTML formatado pra uma pessoa ver, devolve JSON pra outro programa ler. O Next.js (frontend) é esse "outro programa".

1. O arquivo PHP como "endpoint"

No projeto deste curso, cada arquivo PHP é uma URL. Sem frameworks, sem roteadores. Se você criar backend/api/cursos.php, ele fica acessível em http://localhost:8000/api/cursos.php. Simples assim.

Endpoint é o nome bonito pra "uma URL que a gente pode chamar de um programa". GET http://localhost:8000/api/cursos.php = endpoint de listar cursos.

2. De $GET/$POST para JSON

Você já usou $_POST['campo'] pra ler dados de um formulário HTML. O Next.js não manda formulários — ele manda JSON no corpo da requisição. Pra ler isso em PHP:

// Lê o corpo JSON que o Next.js mandou
$body = json_decode(file_get_contents('php://input'), true);

// Agora $body é um array PHP normal:
$email = $body['email'];
$senha = $body['password'];

E pra devolver a resposta, em vez de echo "<p>Bem-vindo</p>":

header('Content-Type: application/json; charset=utf-8');
echo json_encode(['sucesso' => true, 'usuario' => $nome]);
json_encode() converte array PHP → texto JSON
['id' => 1, 'nome' => 'Ana'] vira {"id":1,"nome":"Ana"}

3. PDO — conexão com o banco do jeito seguro

Você provavelmente viu mysqli_connect() ou mysqli_query($conn, "SELECT ..."). PDO é parecido, mas tem uma vantagem enorme: prepared statements, que protegem contra SQL Injection:

// PERIGOSO — SQL Injection possível:
$resultado = mysqli_query($conn, "SELECT * FROM users WHERE email = '$email'");

// SEGURO com PDO — o ? é um placeholder, o banco insere o valor de forma segura:
$stmt = $pdo->prepare("SELECT * FROM users WHERE email = ?");
$stmt->execute([$email]);
$usuario = $stmt->fetch(); // array: ['id' => 1, 'email' => 'ana@...']

O ? no SQL é substituído pelo valor que você passa no execute(). O banco garante que esse valor é tratado como dado, nunca como código SQL.

4. $_SESSION — você já conhece isso

Sessão PHP funciona exatamente como você aprendeu: session_start() no topo, $_SESSION['chave'] = valor pra guardar. A diferença é que o Next.js e o PHP rodam em portas diferentes — o browser manda o cookie de sessão (PHPSESSID) automaticamente nas requisições graças ao withCredentials: true que será configurado no Next.js.

session_start();
$_SESSION['user_id'] = 5;  // guarda quem está logado
// Na próxima requisição do mesmo usuário:
$id = $_SESSION['user_id']; // ainda está aqui

5. CORS — por que os browsers bloqueiam

Por segurança, o browser bloqueia requests de localhost:3000 (Next.js) para localhost:8000 (PHP) — portas diferentes = origens diferentes. A solução é o PHP dizer "pode, eu aceito chamadas de localhost:3000":

header('Access-Control-Allow-Origin: http://localhost:3000');
header('Access-Control-Allow-Credentials: true');

Esse header já está em api/cors.php, que você inclui no começo de todo endpoint.

Preflight (OPTIONS) — antes de toda requisição POST/PUT/DELETE, o browser manda uma requisição "OPTIONS" perguntando "posso?". É preciso responder 200 OK nessa requisição. Está tratado em cors.php também.

6. Padrão de cada arquivo de endpoint

Todo endpoint do projeto segue este esqueleto — você vai repetir isso em cada tarefa:

<?php
require_once __DIR__ . '/../cors.php';   // CORS + session_start()
require_once __DIR__ . '/../db.php';     // $pdo (conexão com banco)

// 1. Verificar o método HTTP
if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
    http_response_code(405);
    json_out(['error' => 'Método não permitido']);
    exit;
}

// 2. Verificar se está logado (quando necessário)
if (!isset($_SESSION['user_id'])) {
    http_response_code(401);
    json_out(['error' => 'Não autenticado']);
    exit;
}

// 3. Ler dados do body JSON
$body = json_decode(file_get_contents('php://input'), true);

// 4. Fazer algo com o banco
$stmt = $pdo->prepare("SELECT * FROM tabela WHERE campo = ?");
$stmt->execute([$valor]);
$resultado = $stmt->fetchAll();

// 5. Devolver JSON
json_out($resultado);
