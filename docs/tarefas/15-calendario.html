Calendário de atividade

Mesma lógica da tarefa 14 (agrupar attempts por período), só que por dia em vez de por semana, e devolvendo um "nível de intensidade" em vez de números brutos — é o heatmap de atividade (tipo o do GitHub) que aparece na tela de progresso.

Passo a passo (com dicas)

1

Controller

Adicione um método calendar no StatsController. A ideia:

  1. Busque as attempts do usuário do último ano (Carbon::now()->subYear()).
  2. Agrupe por dia usando ->groupBy(fn ($a) => $a->created_at->format('Y-m-d')) — isso transforma a coleção num array onde a chave é a data e o valor é a lista de tentativas daquele dia.
  3. Pra cada dia do agrupamento, devolva ['date' => $data, 'level' => $nivel], onde o nível é calculado a partir da quantidade de tentativas — por exemplo: 0 tentativas = nível 0, 1-2 = nível 1, 3-5 = nível 2, 6+ = nível 3.
public function calendar(Request $request)
{
    $attempts = Attempt::where('user_id', $request->user()->id)
        ->where('created_at', '>=', Carbon::now()->subYear())
        ->get()
        ->groupBy(fn ($a) => $a->created_at->format('Y-m-d'));

    $days = $attempts->map(function ($dayAttempts, $date) {
        $count = $dayAttempts->count();

        $level = match (true) {
            $count >= 6 => 3,
            $count >= 3 => 2,
            $count >= 1 => 1,
            default => 0,
        };

        return ['date' => $date, 'level' => $level];
    })->values();

    return response()->json($days);
}

Repare que essa resposta só inclui dias com pelo menos uma tentativa — o frontend já sabe preencher os dias "vazios" com nível 0 por conta própria.
