Detalhe do curso e aulas

Hoje existem três páginas estáticas separadas: cursos/basico/page.tsx, cursos/intermediario/page.tsx, cursos/avancado/page.tsx. Com a API devolvendo o curso pelo slug, podemos unificar as três numa rota dinâmica cursos/[slug]/page.tsx.

Passo 1 — Criar a rota dinâmica

Apague as pastas basico/, intermediario/ e avancado/ dentro de app/cursos/. Crie:

frontend/app/cursos/[slug]/page.tsx
import { fetchFromApi } from "@/app/_lib/server-api"
import { CourseLessons } from "@/app/_components/cursos/course-lessons"

type Lesson = { id: number; title: string; duration: string; youtube_id: string }
type CourseDetail = { slug: string; title: string; lessons: Lesson[] }

export default async function CursoDetalhePage({
    params,
}: {
    params: Promise<{ slug: string }>
}) {
    const { slug } = await params
    const course = await fetchFromApi<CourseDetail>(`/courses.php?slug=${slug}`)

    return <CourseLessons course={course} />
}
