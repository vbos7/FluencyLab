Listar frases (admin)

Última tarefa do guia — e a mais curta, porque é só repetir um padrão que você já viu várias vezes.

Passo a passo

// Admin/PhraseController.php
public function index()
{
    return \App\Models\Phrase::withCount('attempts')->paginate(20);
}

withCount('attempts') é igual ao withSum que você usou na tarefa 17, só que conta quantas tentativas existem em vez de somar uma coluna — útil pro admin ver quais frases são mais praticadas. Pra isso funcionar, adicione o relacionamento no Model Phrase:

// app/Models/Phrase.php
public function attempts()
{
    return $this->hasMany(Attempt::class);
}
Route::middleware(['auth:sanctum', 'admin'])->group(function () {
    // ...
    Route::get('/admin/phrases', [Admin\PhraseController::class, 'index']);
});
