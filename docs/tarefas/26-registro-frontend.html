Tarefa 26 Aluno A Pendente

Conectar o registro

Mesmo padrão da tarefa 25, com uma pegadinha: o formulário atual em register-form.tsx não tem um campo de nome, mas o backend exige (RegisterRequest na tarefa 03). Você vai precisar adicionar o campo.

Passos

1

Adicionar o campo nome

Em register-form.tsx, adicione o estado e o input de nome, seguindo o mesmo padrão do campo de email que já existe no arquivo:

const [name, setName] = useState("")
// e o input correspondente com value={name} onChange={(e) => setName(e.target.value)}
2

Função de registro

import { apiClient } from "@/app/_lib/api"

async function handleRegister() {
    setError(null)
    setLoading(true)
    try {
        await apiClient.post("/auth/register.php", {
            name,
            email,
            password,
            password_confirmation: confirmPassword,  // nome que o PHP espera
        })
        router.push("/home")
    } catch {
        setError("Não foi possível criar a conta. Confira os dados.")
    } finally {
        setLoading(false)
    }
}
password_confirmation — o PHP verifica um campo com exatamente esse nome. Se você mandar confirmPassword ou confirm_password, a validação vai falhar.
