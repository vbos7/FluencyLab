Tarefa 26 Pessoa A Pendente

Conectar o registro

Mesmo padrão da tarefa 25 — só que com uma pegadinha: o formulário de registro (frontend/app/_components/auth/register-form.tsx) hoje só tem campos de email, password e confirmPassword. Falta o campo name, que o backend exige (lembra do RegisterRequest da tarefa 02?). Essa tarefa inclui adicionar esse campo no formulário antes de conectar com a API.

Passo a passo

1

Adicionar o campo "nome"

No topo do componente, junto dos outros useState:

const [name, setName] = useState("")

No JSX, copie o bloco do campo de email (deve ter um <input> com ícone, dentro de uma div com a classe de fieldClass("email")) e adapte pra nome — mesma estrutura, só trocando o ícone (pode usar UserIcon, que já está importado no arquivo), o type="text", o value={name} e o onChange={(e) => setName(e.target.value)}. Coloque esse bloco antes do campo de email.

2

Função de registro

frontend/app/_components/auth/register-form.tsx
import { apiClient } from "@/app/_lib/api"
import Cookies from "js-cookie"

// ...

const [error, setError] = useState<string | null>(null)
const [loading, setLoading] = useState(false)

async function handleRegister() {
    setError(null)
    setLoading(true)

    try {
        const response = await apiClient.post("/register", {
            name,
            email,
            password,
            password_confirmation: confirmPassword,
        })
        const { token } = response.data

        Cookies.set("token", token, { expires: 7 })
        router.push("/home")
    } catch (err) {
        setError("Não foi possível criar a conta. Confira os dados e tente de novo.")
    } finally {
        setLoading(false)
    }
}
password_confirmation, não confirmPassword O estado local em React pode se chamar como você quiser (confirmPassword), mas o nome do campo que a API espera é password_confirmation (foi assim que definimos a regra 'confirmed' no RegisterRequest da tarefa 02 — o Laravel procura automaticamente por um campo com esse sufixo exato). Mande o valor de confirmPassword, mas com essa chave.
3

Trocar o botão "Criar conta"

Igual fez na tarefa 25: troque o onClick do botão de submit pra chamar handleRegister, adicione disabled={loading} e mostre {error} se existir.

Como testar

Preencha o formulário de cadastro pela tela, com um email novo. Deve te levar pra /home já logado — confira o cookie token no DevTools, igual na tarefa anterior.
