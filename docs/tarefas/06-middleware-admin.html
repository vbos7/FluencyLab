Tarefa 06 Pessoa A Pendente

Middleware de administrador

Essa tarefa não cria nenhuma rota nova — ela cria uma trava reutilizável que vai ser usada lá na frente, nas tarefas de Admin (21 a 23). É rápida, mas importante entender bem o que é um middleware customizado.

O que você vai aprender

  • Como criar um middleware do zero (até agora você só usou o auth:sanctum, que já vem pronto).
  • Como combinar dois middlewares numa mesma rota.

Por que isso existe

O auth:sanctum responde uma pergunta: "essa pessoa está logada?". Mas pras rotas de admin precisamos de uma segunda pergunta: "essa pessoa logada é um admin?". Em PHP puro isso seria um if ($_SESSION['papel'] !== 'admin') { /* bloqueia */ } copiado e colado no topo de cada arquivo administrativo. Um middleware deixa essa checagem num lugar só, reaproveitável em quantas rotas precisar.

Passo a passo

1

Criar o middleware

docker compose exec backend php artisan make:middleware EnsureUserIsAdmin
backend/app/Http/Middleware/EnsureUserIsAdmin.php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class EnsureUserIsAdmin
{
    public function handle(Request $request, Closure $next): Response
    {
        if ($request->user()?->role !== 'admin') {
            return response()->json(['message' => 'Acesso restrito a administradores.'], 403);
        }

        // $next($request) é o que deixa a requisição seguir adiante,
        // até chegar no Controller. Se você não chamar isso, a
        // requisição simplesmente para aqui.
        return $next($request);
    }
}

$request->user()?->role — o ?-> é o "null-safe operator" do PHP: se $request->user() for nulo (ninguém logado), em vez de dar erro, a expressão inteira já vira null, que é diferente de 'admin', e a checagem barra normalmente.

2

Dar um "apelido" pro middleware

Pra poder usar 'admin' nas rotas (em vez do nome completo da classe), registre um apelido:

backend/bootstrap/app.php
use App\Http\Middleware\EnsureUserIsAdmin;

->withMiddleware(function (Middleware $middleware): void {
    $middleware->alias([
        'admin' => EnsureUserIsAdmin::class,
    ]);
})
3

Como vai ficar usado (referência pra tarefa 21+)

Você não precisa criar essas rotas agora — é só pra você já entender o que vem pela frente:

Route::middleware(['auth:sanctum', 'admin'])->group(function () {
    Route::get('/admin/stats', [AdminController::class, 'stats']);
    // ...
});

Dois middlewares na mesma rota, em ordem: primeiro confere se está logado, depois confere se é admin. Se qualquer um dos dois barrar, a requisição nem chega no Controller.
