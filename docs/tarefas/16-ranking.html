Tarefa 16 Aluno D Pendente

Leaderboard (ranking)

A consulta mais "SQL" do módulo: LEFT JOIN + SUM + GROUP BY + ORDER BY numa tacada só.

O que é novo: LEFT JOIN

SELECT u.id, u.name, COALESCE(SUM(rp.points), 0) AS xp
FROM users u
LEFT JOIN ranking_points rp ON rp.user_id = u.id
GROUP BY u.id, u.name
ORDER BY xp DESC

LEFT JOIN inclui todos os usuários mesmo que não tenham nenhum ponto em ranking_points (aparecem com xp = 0). Um INNER JOIN normal excluiria esses usuários.

O arquivo

backend/api/ranking.php
<?php
require_once __DIR__ . '/cors.php';
require_once __DIR__ . '/db.php';

// Público — qualquer pessoa pode ver o ranking
if ($_SERVER['REQUEST_METHOD'] !== 'GET') { json_out(['error' => 'Método não permitido'], 405); exit; }

$stmt = $pdo->query("
    SELECT u.id, u.name, COALESCE(SUM(rp.points), 0) AS xp
    FROM users u
    LEFT JOIN ranking_points rp ON rp.user_id = u.id
    GROUP BY u.id, u.name
    ORDER BY xp DESC
    LIMIT 30
");

$lista = array_map(function ($user) {
    $xp    = (int) $user['xp'];
    $nivel = 1;
    while ($xp >= $nivel * 150) $nivel++;   // nível N exige N×150 de XP
    return ['id' => $user['id'], 'name' => $user['name'], 'xp' => $xp, 'level' => $nivel];
}, $stmt->fetchAll());

json_out($lista);

Como testar

curl http://localhost:8000/api/ranking.php

Sem cookie — é público. Pratica algumas frases com dois usuários diferentes pra ver a disputa de posições.
