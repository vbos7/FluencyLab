Tarefa 24

Fundamentos do frontend — Como o Next.js fala com o PHP

O backend está pronto, mas o frontend ainda mostra dados mockados. Esta tarefa configura o "telefone" entre o Next.js e o PHP. Todo o time deve ler antes de começar as tarefas 25-36.

1. Sessão PHP + cookie automático

O PHP, quando você chama session_start(), cria automaticamente um cookie chamado PHPSESSID no browser. O browser guarda esse cookie e o envia em toda requisição seguinte pra o mesmo servidor — sem você precisar fazer nada. É exatamente como $_SESSION funciona em qualquer site PHP normal, só que aqui o "site" é o Next.js rodando separado.

A única configuração extra necessária é dizer pro axios que ele deve enviar cookies nas requisições cross-origin (localhost:3000 → localhost:8000):

withCredentials: true

Só isso. Sem guardar token manualmente, sem Authorization: Bearer, sem js-cookie.

2. Instalar axios

cd frontend
npm install axios

3. Cliente para Client Components ("use client")

frontend/app/_lib/api.ts
"use client"

import axios from "axios"

export const apiClient = axios.create({
    baseURL: process.env.NEXT_PUBLIC_API_URL,
    headers: { Accept: "application/json" },
    withCredentials: true,   // envia o cookie PHPSESSID em todo request
})

Pronto. Quando o PHP criar a sessão no login, o cookie vai pro browser, e em todo request seguinte via apiClient esse cookie já viaja junto.

4. Cliente para Server Components (fetchFromApi)

Server Components rodam no servidor do Next.js — não têm acesso ao browser nem ao cookie diretamente. Para eles, precisamos encaminhar o cookie da requisição incoming:

frontend/app/_lib/server-api.ts
import { cookies } from "next/headers"

export async function fetchFromApi<T = unknown>(path: string): Promise<T> {
    const cookieStore = await cookies()
    const cookieHeader = cookieStore.toString()   // ex: "PHPSESSID=abc123"

    const res = await fetch(`${process.env.NEXT_PUBLIC_API_URL}${path}`, {
        headers: {
            Accept: "application/json",
            Cookie: cookieHeader,   // repassa o cookie do usuário pro PHP
        },
        cache: "no-store",
    })

    if (!res.ok) throw new Error(`Erro ao buscar ${path}: ${res.status}`)
    return res.json()
}

5. Variável de ambiente

O endereço da API já está no docker-compose.yml. Pra rodar o Next.js localmente fora do Docker (npm run dev), crie também:

frontend/.env.local
NEXT_PUBLIC_API_URL=http://localhost:8000/api
Atenção nas URLs dos endpoints: como o backend é PHP puro (sem router), as URLs incluem a extensão .php:
/api/auth/login.php, /api/courses.php, /api/practice/phrases.php, etc.
