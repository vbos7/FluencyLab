Conectar o perfil

Dois pontos de integração aqui: a página em si (Server Component, busca os dados) e o diálogo de edição (Client Component, já tem até um comentário // TODO: chamada de API esperando por você).

Parte 1 — Buscar dados reais na página

Hoje profile/page.tsx tem um objeto const USER = {...} fixo no topo do arquivo. Troque por uma busca real:

frontend/app/profile/page.tsx
import { fetchFromApi } from "@/app/_lib/server-api"

type User = {
    id: number
    name: string
    email: string
    role: string
}

export default async function ProfilePage() {
    const user = await fetchFromApi<User>("/profile")

    // ... use user.name, user.email no lugar do USER.name, USER.email antigo
}
Nem todo campo do mock existe na API ainda O objeto USER mockado tinha campos como rankLabel, stats (array de pontos/sequência/etc) e xp, que vêm de outras rotas (tarefa 13 do backend, tarefa 17). Pra esta tarefa, foque em conectar name/email/role (que já existem em GET /api/profile) — os outros campos podem continuar mockados por enquanto, ou você pode buscar de fetchFromApi("/user/stats") em paralelo, se quiser ir além.

Parte 2 — Salvar edição

frontend/app/_components/profile/edit-profile-dialog.tsx
import { apiClient } from "@/app/_lib/api"

// ...

async function handleSave() {
    try {
        await apiClient.put("/profile", {
            name: form.name,
            email: form.email,
        })
        setOpen(false)
        // recarrega a página pra refletir os dados novos
        window.location.reload()
    } catch (err) {
        console.error("Erro ao salvar perfil:", err)
    }
}
window.location.reload() — uma solução simples, não a ideal Recarregar a página inteira funciona, mas é um pouco bruto (perde scroll, estado de outros componentes, etc). O jeito mais "correto" no Next.js seria usar router.refresh() (do useRouter), que busca os dados do Server Component de novo sem recarregar a página inteira. Fica como uma melhoria pra Fase 2 — para o objetivo desta tarefa, reload() já resolve.

Como testar

Edite seu nome pelo formulário e confirme que a mudança aparece depois de salvar. Confira também direto no backend: docker compose exec backend php artisan tinker e User::find(1) deve mostrar o nome atualizado.
