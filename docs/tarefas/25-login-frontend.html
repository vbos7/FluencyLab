Conectar o login

O LoginForm em frontend/app/_components/auth/login-form.tsx hoje só navega pra /home sem chamar nenhuma API. Aqui você troca isso por uma chamada real.

Onde mexer

No componente, o botão "Entrar" hoje é:

onClick={() => {
    localStorage.removeItem("fluency-lab:mode")
    router.push("/home")
}}

Troque por:

Código da função de login

frontend/app/_components/auth/login-form.tsx
import { apiClient } from "@/app/_lib/api"

const [error, setError]   = useState<string | null>(null)
const [loading, setLoading] = useState(false)

async function handleLogin() {
    setError(null)
    setLoading(true)

    try {
        await apiClient.post("/auth/login.php", { email, password })
        // O PHP criou a sessão e o browser recebeu o cookie PHPSESSID
        // Não precisamos guardar nada manualmente!
        localStorage.removeItem("fluency-lab:mode")
        router.push("/home")
    } catch {
        setError("Email ou senha incorretos.")
    } finally {
        setLoading(false)
    }
}
<button onClick={handleLogin} disabled={loading}>
    {loading ? "Entrando..." : "Entrar"}
</button>
{error && <p className="text-red-500 text-sm mt-2">{error}</p>}
Por que não guardamos o cookie? O browser faz isso automaticamente. Quando o PHP responde com o header Set-Cookie: PHPSESSID=..., o browser guarda e envia em todo request seguinte — o withCredentials: true do axios (configurado na tarefa 24) é o que autoriza isso cross-origin.

Como testar

Cadastre um usuário (pelo curl da tarefa 03 ou pela tela de registro depois da tarefa 26) e faça login pela tela. Abra DevTools → Application → Cookies → localhost e confirme que o cookie PHPSESSID aparece.
