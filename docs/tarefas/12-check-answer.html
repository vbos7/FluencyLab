Tarefa 12 Pessoa B Pendente

Submeter e corrigir uma tradução

Esta tarefa junta tudo que você construiu até aqui: pega a frase (tarefa 10), manda pro AiCorrectionService (tarefa 11), salva o resultado numa tabela nova (attempts) e calcula o XP do usuário — exatamente o fluxo que o frontend espera de POST /api/practice/check-answer.

O que você vai aprender

  • Como injetar uma Service class no Controller (em vez de instanciar com new).
  • Como gravar o resultado de uma chamada externa (JSON da IA) numa coluna do tipo json.

Passo a passo

1

Migration + Model Attempt

docker compose exec backend php artisan make:model Attempt -m
backend/database/migrations/..._create_attempts_table.php
public function up(): void
{
    Schema::create('attempts', function (Blueprint $table) {
        $table->id();
        $table->foreignId('user_id')->constrained()->cascadeOnDelete();
        $table->foreignId('phrase_id')->constrained()->cascadeOnDelete();
        $table->text('answer_given');
        $table->json('ai_feedback');      // o JSON inteiro que a IA devolveu
        $table->boolean('is_correct');
        $table->unsignedTinyInteger('score');   // 0 a 100
        $table->unsignedSmallInteger('xp_earned');
        $table->timestamps();
    });
}
backend/app/Models/Attempt.php
class Attempt extends Model
{
    protected $fillable = [
        'user_id', 'phrase_id', 'answer_given',
        'ai_feedback', 'is_correct', 'score', 'xp_earned',
    ];

    protected $casts = [
        'ai_feedback' => 'array',   // o Eloquent já converte JSON <-> array PHP sozinho
        'is_correct' => 'boolean',
    ];
}
$casts Sem isso, $attempt->ai_feedback viria como uma string JSON crua. Com 'ai_feedback' => 'array', o Eloquent já devolve um array PHP pronto pra usar — e o inverso também funciona: se você atribuir um array PHP, ele já converte pra JSON antes de salvar.
2

Form Request

docker compose exec backend php artisan make:request CheckAnswerRequest
public function authorize(): bool { return true; }

public function rules(): array
{
    return [
        'phrase_id' => ['required', 'exists:phrases,id'],
        'answer' => ['required', 'string'],
    ];
}

'exists:phrases,id' é uma regra nova: confere se aquele phrase_id realmente existe na tabela phrases antes de aceitar a requisição — evita ter que checar isso na mão no Controller.

3

Controller

backend/app/Http/Controllers/PracticeController.php
use App\Http\Requests\CheckAnswerRequest;
use App\Models\Attempt;
use App\Models\Phrase;
use App\Services\AiCorrectionService;

public function checkAnswer(CheckAnswerRequest $request, AiCorrectionService $aiService)
{
    $data = $request->validated();
    $phrase = Phrase::findOrFail($data['phrase_id']);

    $feedback = $aiService->correctTranslation(
        pt: $phrase->pt,
        enReference: $phrase->en,
        userAnswer: $data['answer'],
    );

    $xp = $this->calculateXp($feedback['score']);

    $attempt = Attempt::create([
        'user_id' => $request->user()->id,
        'phrase_id' => $phrase->id,
        'answer_given' => $data['answer'],
        'ai_feedback' => $feedback,
        'is_correct' => $feedback['is_correct'],
        'score' => $feedback['score'],
        'xp_earned' => $xp,
    ]);

    return response()->json([
        'feedback' => $feedback,
        'xp_earned' => $xp,
        'attempt_id' => $attempt->id,
    ]);
}

private function calculateXp(int $score): int
{
    // Mesmas faixas que já existiam no protótipo do frontend —
    // só que agora o "score" vem da IA, não de um cálculo de
    // similaridade de texto.
    return match (true) {
        $score >= 95 => 25,
        $score >= 70 => 15,
        $score >= 40 => 8,
        default => 3,
    };
}
AiCorrectionService $aiService no parâmetro Igual o Laravel injeta automaticamente o Form Request validado, ele também injeta qualquer outra classe que você pedir no parâmetro do método — isso se chama injeção de dependência. Você não precisa escrever new AiCorrectionService() em lugar nenhum; o framework resolve isso sozinho.
4

Registrar a rota

backend/routes/api.php
Route::middleware('auth:sanctum')->group(function () {
    // ... rotas de /profile que já estavam aqui
    Route::post('/practice/check-answer', [PracticeController::class, 'checkAnswer']);
});

Precisa estar logado — afinal a tentativa é gravada associada a um user_id.

Como testar

curl -X POST http://localhost:8000/api/practice/check-answer \
  -H "Authorization: Bearer SEU_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{"phrase_id": 1, "answer": "I want a coffee please"}'

A resposta deve demorar 1-3 segundos (é a chamada real pra OpenAI) e trazer o feedback completo + o XP ganho.
