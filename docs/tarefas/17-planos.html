Tarefa 17 Aluno D Pendente

Planos (Free/Pro)

Um SELECT simples. O ponto de atenção aqui é a coluna features, que é JSON no banco — o MySQL armazena como texto JSON, mas o PHP recebe como string e precisa decodificar antes de devolver.

O arquivo

backend/api/plans.php
<?php
require_once __DIR__ . '/cors.php';
require_once __DIR__ . '/db.php';

// Público — qualquer um vê os planos disponíveis antes de se cadastrar
if ($_SERVER['REQUEST_METHOD'] !== 'GET') { json_out(['error' => 'Método não permitido'], 405); exit; }

$stmt  = $pdo->query("SELECT * FROM plans ORDER BY price");
$plans = $stmt->fetchAll();

// A coluna features é JSON no banco — vem como string, precisa decodificar
foreach ($plans as &$plan) {
    $plan['features'] = json_decode($plan['features'] ?? '[]', true);
}

json_out($plans);
foreach ($plans as &$plan) — o & antes de $plan é uma referência. Sem ele, você modifica uma cópia e a variável original não muda. Com &, você modifica o elemento original dentro do array.
