Tarefa 10 Pessoa B Pendente

Frases de prática

Aqui começa o módulo de Practice — o coração do app. Importante entender a estrutura de dados antes de codar: o exercício de prática não é ligado a uma aula específica nem é múltipla escolha. São frases soltas, em português, que o usuário traduz pra inglês — a correção (de verdade, por IA) vem nas tarefas 11 e 12.

O que você vai aprender

  • Como filtrar resultados a partir de parâmetros da URL (query string) — ex: /api/practice/phrases?category=Trabalho.

Passo a passo

1

Migration + Model

docker compose exec backend php artisan make:model Phrase -m
backend/database/migrations/..._create_phrases_table.php
public function up(): void
{
    Schema::create('phrases', function (Blueprint $table) {
        $table->id();
        $table->text('pt');                 // frase em português
        $table->text('en');                 // tradução de referência (a IA usa isso de exemplo)
        $table->string('difficulty');       // "easy" | "medium" | "hard"
        $table->string('category');         // "Cotidiano", "Trabalho", "Viagem", etc.
        $table->timestamps();
    });
}
backend/app/Models/Phrase.php
class Phrase extends Model
{
    protected $fillable = ['pt', 'en', 'difficulty', 'category'];
}
2

Seeder

Use as frases que já existem no mock do frontend (frontend/app/_lib/practice.ts, array PHRASES) como fonte — copie pt/en/difficulty/category de lá pro seu PhraseSeeder, igual fez com os cursos na tarefa 07. Não precisa digitar tudo na mão: dá pra escrever um array PHP com os mesmos dados e rodar um foreach chamando Phrase::create().

3

Controller com filtro opcional

docker compose exec backend php artisan make:controller PracticeController --api
backend/app/Http/Controllers/PracticeController.php
use App\Models\Phrase;
use Illuminate\Http\Request;

public function phrases(Request $request)
{
    $query = Phrase::query();

    // ?category=Trabalho na URL vira $request->query('category')
    if ($request->filled('category')) {
        $query->where('category', $request->query('category'));
    }

    if ($request->filled('difficulty')) {
        $query->where('difficulty', $request->query('difficulty'));
    }

    return $query->get();
}
$request->filled() vs $request->has() filled('category') só é verdadeiro se o parâmetro existir e não estiver vazio (?category= não conta). É o jeito mais seguro de checar "o usuário realmente quer filtrar por isso".
backend/routes/api.php
use App\Http\Controllers\PracticeController;

Route::get('/practice/phrases', [PracticeController::class, 'phrases']);

Como testar

curl http://localhost:8000/api/practice/phrases
curl "http://localhost:8000/api/practice/phrases?category=Trabalho"
