Listar frases de prática

Primeira tarefa do seu módulo! Os exercícios de prática não são múltipla escolha — são frases em português pra o usuário traduzir pra inglês. A correção (por IA) vem na tarefa 11.

O que é novo: WHERE com filtros opcionais

O endpoint aceita parâmetros opcionais na URL. Se vierem, filtra; se não vierem, devolve tudo.

backend/api/practice/phrases.php
<?php
require_once __DIR__ . '/../cors.php';
require_once __DIR__ . '/../db.php';

if ($_SERVER['REQUEST_METHOD'] !== 'GET') {
    json_out(['error' => 'Método não permitido'], 405);
    exit;
}

$sql    = "SELECT * FROM phrases WHERE 1=1";
$params = [];

// ?category=Trabalho — filtra por categoria
if (!empty($_GET['category'])) {
    $sql    .= " AND category = ?";
    $params[] = $_GET['category'];
}

// ?difficulty=easy — filtra por dificuldade
if (!empty($_GET['difficulty'])) {
    $sql    .= " AND difficulty = ?";
    $params[] = $_GET['difficulty'];
}

$stmt = $pdo->prepare($sql);
$stmt->execute($params);
json_out($stmt->fetchAll());
WHERE 1=1 é um truque de SQL: 1=1 é sempre verdadeiro, então não filtra nada por padrão. Mas permite adicionar AND ... dinamicamente sem precisar checar "é o primeiro filtro ou não".

Inserir as frases no banco

Copie as frases do arquivo de mock do frontend (frontend/app/_lib/practice.ts, array FRASES) para um arquivo SQL e execute:

INSERT INTO phrases (pt, en, difficulty, category) VALUES
('Eu gostaria de um café, por favor.', 'I would like a coffee, please.', 'easy', 'Cotidiano'),
('Onde fica a estação de trem mais próxima?', 'Where is the nearest train station?', 'easy', 'Viagem')
-- ... continue para todas as frases
docker compose exec -T mysql mysql --default-character-set=utf8mb4 \
  -u root -proot fluency_lab < backend/sql/seeds-frases.sql

Como testar

curl "http://localhost:8000/api/practice/phrases.php"
curl "http://localhost:8000/api/practice/phrases.php?category=Trabalho"
