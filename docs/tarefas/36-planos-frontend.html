Conectar os planos

Última tarefa do guia inteiro — backend e frontend. Dois pontos, igual o padrão de Cursos (tarefas 30/31): a listagem de planos (remove "use client" desnecessário, busca real) e o checkout (Client Component, chamada de verdade no lugar do setTimeout fake).

Parte 1 — Listagem de planos

planos/page.tsx hoje começa com "use client" mas só tem um array fixo (featuresF) — mesma situação da tarefa 30. Remova a diretiva e busque os dados reais:

import { fetchFromApi } from "@/app/_lib/server-api"
import CheckoutModalWrapper from "@/app/_components/checkout-modal-wrapper" // ver Parte 2

type Plan = { id: number; name: string; price: string; features: { label: string; included: boolean }[] }

export default async function PlanosPage() {
    const plans = await fetchFromApi<Plan[]>("/plans")
    // ... renderiza plans.map(...) no lugar do array featuresF fixo
}

Parte 2 — Checkout chamando a API de verdade

O CheckoutModal hoje só recebe onClose como prop, e o "pagamento" é só um setTimeout fake. Duas mudanças: precisa saber qual plano está sendo assinado (nova prop), e o handleSubmit precisa virar uma chamada real.

1

Adicionar a prop planId

frontend/app/_components/checkout-modal.tsx
type Props = {
    planId: number
    onClose: () => void
}

export default function CheckoutModal({ planId, onClose }: Props) {
    // ...
}

E no lugar de onde a página abre o modal hoje (provavelmente um useState de "qual plano foi clicado" + renderização condicional do <CheckoutModal />), passe o planId correspondente ao botão que o usuário clicou.

2

Trocar o handleSubmit fake pela chamada real

import { apiClient } from "@/app/_lib/api"

async function handleSubmit() {
    setLoading(true)
    try {
        await apiClient.post("/plans/subscribe", { plan_id: planId })
        setSuccess(true)
    } catch (err) {
        console.error("Erro ao assinar plano:", err)
    } finally {
        setLoading(false)
    }
}

Reaproveita exatamente a mesma estrutura de loading/success que já existia — só o miolo da função mudou, de um setTimeout simulado pra uma chamada real à rota que vocês construíram na tarefa 19 do backend.

Como testar

Acesse localhost:3000/planos, clique em assinar o plano Pro, complete o checkout. Confira no banco que a assinatura foi registrada:
