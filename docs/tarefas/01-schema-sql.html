Criar as tabelas no banco (SQL)

Essa tarefa já foi feita antes de vocês começarem — o arquivo backend/sql/schema.sql já existe e já foi executado no banco. Leia esta página pra entender o que tem lá e por que as tabelas foram criadas dessa forma.

Por que criar tabelas com SQL direto?

Em frameworks como Laravel, você usa "migrations" (scripts PHP que criam tabelas). Aqui, como estamos em PHP puro, criamos direto com SQL — a linguagem que o banco realmente entende. O resultado é o mesmo: as tabelas existem no banco.

Conceitos importantes

1

PRIMARY KEY — o ID único de cada linha

CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    -- ...
);

INT AUTO_INCREMENT PRIMARY KEY significa: número inteiro, que aumenta sozinho a cada novo registro, e que identifica aquela linha de forma única. Todo INSERT numa tabela com isso não precisa informar o id — o banco gera automaticamente.

2

FOREIGN KEY — a ligação entre tabelas

CREATE TABLE lessons (
    id        INT AUTO_INCREMENT PRIMARY KEY,
    course_id INT NOT NULL,
    title     VARCHAR(100) NOT NULL,
    -- ...
    FOREIGN KEY (course_id) REFERENCES courses(id) ON DELETE CASCADE
);

FOREIGN KEY (course_id) REFERENCES courses(id) diz: "a coluna course_id desta tabela deve ser um id que existe na tabela courses". O banco rejeita qualquer INSERT em lessons onde course_id não existe em courses.

ON DELETE CASCADE: se o curso for apagado, suas aulas somem junto automaticamente.

3

ENUM — lista de valores permitidos

role ENUM('student','admin') NOT NULL DEFAULT 'student'

O banco só aceita os valores da lista. Tenta inserir 'superadmin' e ele rejeita. É como uma validação automática na estrutura do banco.

Como executar o schema num banco novo

docker compose exec -T mysql mysql --default-character-set=utf8mb4 \
  -u root -proot fluency_lab < backend/sql/schema.sql

A flag --default-character-set=utf8mb4 é obrigatória — sem ela, os acentos ficam corrompidos no banco.

Para verificar que as tabelas existem

docker compose exec mysql mysql -u root -proot fluency_lab -e "SHOW TABLES;"
