Tarefa 32 Pessoa B Pendente

Carregar as frases de prática

Boa notícia: practice/page.tsx já é um Server Component, e o PracticeController já é um Client Component que recebe as frases prontas via prop — ou seja, o projeto já estava estruturado exatamente do jeito que a tarefa 24 ensina. Essa tarefa é só trocar de onde vem o array de frases.

Hoje

frontend/app/practice/page.tsx (atual)
import { FRASES } from "@/app/_lib/practice"
import { PracticeController } from "@/app/_components/practice/practice-controller"
import NavLayout from "@/app/_layouts/nav-layout"

export default function PracticePage() {
    const phrases = FRASES.flat()

    return (
        <NavLayout>
            <PracticeController phrases={phrases} />
        </NavLayout>
    )
}

Passo a passo

1

Trocar a fonte dos dados

frontend/app/practice/page.tsx
import { fetchFromApi } from "@/app/_lib/server-api"
import { PracticeController } from "@/app/_components/practice/practice-controller"
import NavLayout from "@/app/_layouts/nav-layout"

type Phrase = { id: number; pt: string; en: string; difficulty: string; category: string }

export default async function PracticePage() {
    const phrases = await fetchFromApi<Phrase[]>("/practice/phrases")

    return (
        <NavLayout>
            <PracticeController phrases={phrases} />
        </NavLayout>
    )
}
FRASES.flat() sumiu — por quê? O mock antigo guardava as frases agrupadas em sub-arrays por categoria (por isso o .flat(), que "achata" array de arrays num array só). A tabela phrases do banco já é uma lista simples — GET /api/practice/phrases já devolve no formato achatado, então não precisa mais dessa etapa.
2

Conferir o tipo Phrase dentro do PracticeController

Abra app/_components/practice/practice-controller.tsx e confira o import:

import { type Phrase, type Feedback, scoreAnswer, generateFeedback } from "@/app/_lib/practice"

Por enquanto, deixe como está — scoreAnswer e generateFeedback (a correção por Levenshtein, a "gambiarra" da apresentação) ainda vão ser usados até a próxima tarefa, que troca isso pela correção de verdade por IA. Só confirme que o tipo Phrase ali bate com os campos que a API devolve (id, pt, en, difficulty, category) — se o arquivo _lib/practice.ts tiver um formato de Phrase diferente do mock antigo, ajuste o tipo.

Como testar

Acesse localhost:3000/practice — as frases que aparecem devem ser as que você cadastrou no PhraseSeeder (tarefa 10), não mais o array antigo do _lib/practice.ts.
