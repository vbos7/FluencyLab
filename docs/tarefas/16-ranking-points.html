Pontos de ranking automáticos

Diferente de Progress (calculado na hora), o Ranking tem uma tabela própria: ranking_points. A diferença é que aqui cada linha é um "evento" de pontuação (ex: "+10 pontos por exercício correto"), não um número que vai sendo somado numa coluna só. Isso permite, no futuro, dar bônus por sequência de dias ou por completar um curso, sem precisar reescrever a lógica de pontuação — só registrar mais um tipo de evento.

O que você vai aprender

  • O que é um Eloquent Observer — uma classe que "escuta" eventos de um Model (criado, atualizado, apagado) e reage automaticamente, sem você precisar lembrar de chamar nada manualmente toda vez.

Por que um Observer, e não só somar dentro do PracticeController?

Você poderia simplesmente adicionar umas linhas no checkAnswer() da tarefa 12, calculando e salvando os pontos de ranking ali mesmo. O problema: se amanhã outra parte do sistema também criar uma Attempt (por exemplo, um import de dados, ou um teste automatizado), a pontuação não aconteceria, porque essa lógica só existe dentro daquele Controller específico. Um Observer reage a "uma Attempt foi criada", não importa de onde ela veio — a regra de negócio fica centralizada num lugar só.

Passo a passo

1

Migration + Model

docker compose exec backend php artisan make:model RankingPoint -m
public function up(): void
{
    Schema::create('ranking_points', function (Blueprint $table) {
        $table->id();
        $table->foreignId('user_id')->constrained()->cascadeOnDelete();
        $table->unsignedSmallInteger('points');
        $table->string('reason');     // ex: "Exercício correto"
        $table->timestamp('earned_at');
        $table->timestamps();
    });
}
// app/Models/RankingPoint.php
class RankingPoint extends Model
{
    protected $fillable = ['user_id', 'points', 'reason', 'earned_at'];
}
2

Criar o Observer

docker compose exec backend php artisan make:observer AttemptObserver --model=Attempt
backend/app/Observers/AttemptObserver.php
<?php

namespace App\Observers;

use App\Models\Attempt;
use App\Models\RankingPoint;

class AttemptObserver
{
    public function created(Attempt $attempt): void
    {
        if (! $attempt->is_correct) {
            return;
        }

        RankingPoint::create([
            'user_id' => $attempt->user_id,
            'points' => $attempt->xp_earned,
            'reason' => 'Exercício correto',
            'earned_at' => now(),
        ]);
    }
}

O método created() roda automaticamente toda vez que um Attempt::create(...) é executado em qualquer lugar do sistema — você não precisa chamar nada explicitamente.

3

Registrar o Observer

Um Observer não funciona sozinho — precisa avisar o Laravel que ele existe e a qual Model está "ouvindo":

backend/app/Providers/AppServiceProvider.php
use App\Models\Attempt;
use App\Observers\AttemptObserver;

public function boot(): void
{
    Authenticate::redirectUsing(fn () => null); // já existia, deixe como está

    Attempt::observe(AttemptObserver::class);
}
