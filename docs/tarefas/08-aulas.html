Tarefa 08 Pessoa B Pendente

Aulas de cada curso

Mesma receita da tarefa 07 (migration → model → seeder → controller → rota). Desta vez você mesmo vai escrever a maior parte, só com dicas — se travar em algum passo, volte na tarefa 07 e compare.

O que é novo aqui

  • O relacionamento inverso: belongsTo (uma aula pertence a um curso), complementando o hasMany que você já escreveu no Course.
  • Uma rota com parâmetro na URL: /api/courses/{slug}.

Passo a passo (com dicas)

1

Migration + Model Lesson

docker compose exec backend php artisan make:model Lesson -m

Colunas que a tabela lessons precisa ter (compare com a estrutura de courses da tarefa anterior):

  • course_id — use $table->foreignId('course_id')->constrained()->cascadeOnDelete(); em vez de uma coluna comum. Isso já cria a ligação com a tabela courses e garante que, se um curso for apagado, as aulas dele somem junto (cascadeOnDelete).
  • title (string)
  • duration (string — ex: "12 min")
  • youtube_id (string)
  • order (integer, default 0)

No Model Lesson, o relacionamento inverso ao que você já fez em Course:

public function course()
{
    return $this->belongsTo(Course::class);
}

Não esqueça do $fillable com os campos acima (veja como ficou em Course se tiver dúvida).

2

Seeder

Crie um LessonSeeder com 2-3 aulas pra cada curso (use Course::where('slug', 'basico')->first()->id pra pegar o course_id certo). Registre no DatabaseSeeder, do mesmo jeito que fez com o CourseSeeder.

3

Controller e rota

Adicione um método show no CourseController (o mesmo da tarefa 07, não precisa criar um Controller novo):

public function show(string $slug)
{
    return Course::with('lessons')->where('slug', $slug)->firstOrFail();
}
with('lessons') Sem isso, $course->lessons dispararia uma consulta extra ao banco só quando você acessasse essa propriedade (chamado de "lazy loading"). Com with('lessons'), o Eloquent já busca curso e aulas numa tacada só, antes de devolver a resposta — mais eficiente. 
Route::get('/courses/{slug}', [CourseController::class, 'show']);

Como testar

curl http://localhost:8000/api/courses/basico

Deve devolver o curso com um array lessons dentro.
