Tarefa 30 Pessoa B Pendente

Listar cursos

Primeira tarefa do seu módulo na integração — se ainda não leu a tarefa 24, leia antes (explica Server vs Client Components, que é a base de tudo aqui).

O que tem de diferente nesta tarefa

frontend/app/cursos/page.tsx hoje começa com "use client" — mas, olhando o arquivo, ele não usa useState nem onClick nem nada que realmente precise rodar no navegador (só tem um array fixo de dados e uns links). Isso quer dizer que o "use client" ali está sobrando — é um ótimo primeiro exemplo de quando remover a diretiva, transformando a página de volta num Server Component (o padrão), capaz de buscar dado direto com fetchFromApi.

Passo a passo

1

Remover "use client" e buscar dados reais

frontend/app/cursos/page.tsx
import Link from "next/link"
import NavLayout from "../_layouts/nav-layout"
import { Languages, LibraryBig, Timer } from "lucide-react"
import { fetchFromApi } from "@/app/_lib/server-api"

type Course = {
    id: number
    slug: string
    title: string
    description: string
    level: string
}

export default async function CursosPage() {
    const courses = await fetchFromApi<Course[]>("/courses")

    return (
        <NavLayout>
            {/* ... */}
            {courses.map((course) => (
                <Link key={course.slug} href={`/cursos/${course.slug}`}>
                    {/* ... use course.title, course.description no lugar
                         de nivel.titulo, nivel.descricao ... */}
                </Link>
            ))}
        </NavLayout>
    )
}

Note o que mudou estruturalmente:

  • A função virou async — só é permitido porque agora é um Server Component de verdade.
  • O array niveis hardcoded sumiu — os dados vêm de courses, buscado da API.
  • Os nomes dos campos mudaram: nivel.titulo → course.title, nivel.descricao → course.description (são os nomes das colunas que você criou no banco, na tarefa 07).
Campos visuais (cor, emoji, sombra) não existem no banco O array antigo tinha campos como cor, emoji, bg — isso é puramente visual, não faz sentido guardar no banco de dados. Duas opções: manter um pequeno mapeamento fixo no frontend (ex: um objeto { basico: { cor: "...", emoji: ... }, ... } indexado pelo slug que vem da API), ou simplificar o visual por enquanto. Fica a critério de quem estiver implementando.

Como testar

Acesse localhost:3000/cursos — deve mostrar os 3 cursos que você cadastrou no seeder da tarefa 07, vindos de verdade da API (confira na aba Network do DevTools que não tem mais nenhum array fixo no código fonte da página).
