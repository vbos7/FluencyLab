Detalhe do curso + aulas

Aqui aparece o conceito mais importante do SQL relacional: o JOIN. É como você combina dados de duas tabelas relacionadas numa só consulta.

O que é novo: JOIN

Imagine duas tabelas:

courses: id=1, slug='basico', title='Inglês Básico'
lessons: id=1, course_id=1, title='Aula 1 — Alfabeto'
         id=2, course_id=1, title='Aula 2 — Números'

Um JOIN combina elas numa consulta só, relacionando pela coluna em comum (course_id ↔ id):

SELECT * FROM courses
JOIN lessons ON lessons.course_id = courses.id
WHERE courses.slug = 'basico'

Mas neste endpoint, fazemos duas queries separadas — mais fácil de entender e igualmente correto para o volume de dados que temos:

Adicionando ao arquivo courses.php

backend/api/courses.php (continuação — caso com ?slug=)
// Detalhe por slug: GET /api/courses.php?slug=basico
if (!empty($_GET['slug'])) {
    $slug = $_GET['slug'];

    $stmt = $pdo->prepare("SELECT * FROM courses WHERE slug = ?");
    $stmt->execute([$slug]);
    $course = $stmt->fetch();

    if (!$course) {
        json_out(['error' => 'Curso não encontrado'], 404);
        exit;
    }

    // Busca as aulas desse curso (a FOREIGN KEY garante que só vêm as aulas certas)
    $stmt = $pdo->prepare(
        "SELECT id, title, duration, youtube_id FROM lessons
          WHERE course_id = ? ORDER BY order_num"
    );
    $stmt->execute([$course['id']]);
    $course['lessons'] = $stmt->fetchAll();

    json_out($course);
    exit;
}
$course['lessons'] = $stmt->fetchAll()
O PHP permite adicionar chaves novas a um array a qualquer momento. Aqui, "embutimos" o array de aulas dentro do array do curso antes de devolver tudo como JSON — é exatamente o formato que o Next.js espera.

Como testar

curl "http://localhost:8000/api/courses.php?slug=basico"

Deve devolver o curso com um array lessons com as aulas que você inseriu na tarefa 07.
