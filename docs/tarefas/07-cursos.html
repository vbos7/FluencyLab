Passo a passo

1

Migration e Model

docker compose exec backend php artisan make:model Course -m

O -m já cria a migration junto com o Model, numa tacada só.

backend/database/migrations/..._create_courses_table.php
public function up(): void
{
    Schema::create('courses', function (Blueprint $table) {
        $table->id();
        $table->string('slug')->unique();    // ex: "basico", "intermediario"
        $table->string('title');
        $table->text('description');
        $table->string('level');             // "basico" | "intermediario" | "avancado"
        $table->integer('order')->default(0);
        $table->timestamps();
    });
}
backend/app/Models/Course.php
class Course extends Model
{
    protected $fillable = ['slug', 'title', 'description', 'level', 'order'];

    public function lessons()
    {
        return $this->hasMany(Lesson::class);
    }
}
$fillable — por que é necessário? Por padrão o Eloquent bloqueia o preenchimento em massa (Course::create([...]) com vários campos de uma vez) por segurança — imagine alguém mandando um campo extra malicioso no JSON. O array $fillable é a lista de campos que você está liberando explicitamente pra esse tipo de criação.

Repare no método lessons() — é o relacionamento que vai conectar com a tarefa 08. Já deixe ele aqui, mesmo que o Model Lesson ainda não exista (vamos criar na próxima tarefa).

docker compose exec backend php artisan migrate
2

Seeder

docker compose exec backend php artisan make:seeder CourseSeeder
backend/database/seeders/CourseSeeder.php
use App\Models\Course;

public function run(): void
{
    Course::create([
        'slug' => 'basico',
        'title' => 'Inglês Básico',
        'description' => 'Para quem está começando do zero.',
        'level' => 'basico',
        'order' => 1,
    ]);

    Course::create([
        'slug' => 'intermediario',
        'title' => 'Inglês Intermediário',
        'description' => 'Para quem já entende o básico.',
        'level' => 'intermediario',
        'order' => 2,
    ]);

    Course::create([
        'slug' => 'avancado',
        'title' => 'Inglês Avançado',
        'description' => 'Para quem já se vira bem e quer fluência.',
        'level' => 'avancado',
        'order' => 3,
    ]);
}

Registre o seeder no DatabaseSeeder principal, pra ele rodar junto com os outros:

backend/database/seeders/DatabaseSeeder.php
public function run(): void
{
    $this->call([
        CourseSeeder::class,
    ]);
}
docker compose exec backend php artisan db:seed
3

Controller e rota

docker compose exec backend php artisan make:controller CourseController --api

O --api já gera os métodos index, store, show, update, destroy prontos (vazios) — você só preenche os que for usar.

backend/app/Http/Controllers/CourseController.php
use App\Models\Course;

public function index()
{
    return Course::orderBy('order')->get();
}
backend/routes/api.php
use App\Http\Controllers\CourseController;

Route::get('/courses', [CourseController::class, 'index']);

Sem auth:sanctum — a listagem de cursos é pública, faz sentido alguém ver os cursos disponíveis antes de se cadastrar.

Como testar

curl http://localhost:8000/api/courses

Deve devolver os 3 cursos, sem precisar de token nenhum.
