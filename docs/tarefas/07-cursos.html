Tarefa 07 Aluno B Pendente

Listar cursos

Primeira tarefa do seu módulo! Se ainda não leu a página de Fundamentos e as tarefas 02, 03, leia antes — o esqueleto de endpoint lá vai ser o padrão aqui também.

O que é novo

  • Rota pública — sem verificar sessão. Qualquer pessoa pode ver a lista de cursos.
  • $stmt->fetchAll() em vez de $stmt->fetch() — retorna todas as linhas, não só a primeira.
  • Inserir as aulas de cada curso com INSERT SQL (dados reais, não mock).

O arquivo

backend/api/courses.php (parte GET sem parâmetro)
<?php
require_once __DIR__ . '/cors.php';
require_once __DIR__ . '/db.php';

if ($_SERVER['REQUEST_METHOD'] !== 'GET') {
    json_out(['error' => 'Método não permitido'], 405);
    exit;
}

// Listagem geral (sem parâmetros)
if (empty($_GET['slug'])) {
    $stmt = $pdo->query("SELECT * FROM courses ORDER BY order_num");
    json_out($stmt->fetchAll());
    exit;
}

// Detalhe por slug — veja a tarefa 08
$pdo->query() vs $pdo->prepare()
Use query() quando a SQL não tem variáveis (sem perigo de injection). Use prepare() quando precisa de ? pra inserir dados do usuário com segurança.

Inserir as aulas no banco

Os cursos já vieram do schema.sql. As aulas, você insere agora — crie um INSERT pra cada aula (ou um arquivo sql/seeds-aulas.sql):

INSERT INTO lessons (course_id, title, duration, youtube_id, order_num) VALUES
(1, 'Aula 1 — Alfabeto em inglês', '8:08', 'X5TdMsc4YCg', 1),
(1, 'Aula 2 — Números e cores',    '10:10','YOUTUBE_ID',  2),
(1, 'Aula 3 — Dias da semana',     '9:05', 'YOUTUBE_ID',  3);
-- Repita para course_id = 2 (intermediário) e 3 (avançado)
docker compose exec -T mysql mysql --default-character-set=utf8mb4 \
  -u root -proot fluency_lab < backend/sql/seeds-aulas.sql

Como testar

curl http://localhost:8000/api/courses.php

Deve devolver os 3 cursos. Sem cookie, sem sessão — é público.
