Tarefa 14 Pessoa C Pendente

Progresso semanal

O frontend mostra um gráfico das últimas 12 semanas: quanto XP e quantas tentativas o usuário fez em cada uma. Mesma ideia da tarefa 13 (calcular em cima de attempts), só que agora agrupado por semana.

O que você vai aprender

  • Carbon — a biblioteca de datas que o Laravel já usa por padrão (todo created_at/updated_at já é um objeto Carbon).
  • Como agrupar registros por período usando uma coleção do Eloquent (groupBy).

Passo a passo

1

Controller

backend/app/Http/Controllers/StatsController.php
use Carbon\Carbon;
use App\Models\Attempt;

public function weekly(Request $request)
{
    $start = Carbon::now()->subWeeks(11)->startOfWeek();

    $attempts = Attempt::where('user_id', $request->user()->id)
        ->where('created_at', '>=', $start)
        ->get();

    $weeks = [];

    for ($i = 0; $i < 12; $i++) {
        $weekStart = $start->copy()->addWeeks($i);
        $weekEnd = $weekStart->copy()->endOfWeek();

        $weekAttempts = $attempts->filter(
            fn ($a) => $a->created_at->between($weekStart, $weekEnd)
        );

        $weeks[] = [
            'week' => 'Sem ' . ($i + 1),
            'xp' => $weekAttempts->sum('xp_earned'),
            'treinos' => $weekAttempts->count(),
        ];
    }

    return response()->json($weeks);
}
Por que buscar tudo de uma vez (->get()) em vez de uma query por semana? Daria pra rodar 12 queries (uma por semana, cada uma com seu próprio where created_at between). Mas é mais eficiente trazer todas as tentativas das últimas 12 semanas numa única consulta ao banco, e depois separar em memória com ->filter() — evita ficar abrindo conexão com o banco repetidamente.
2

Rota

Route::get('/user/progress/weekly', [StatsController::class, 'weekly']);

(dentro do mesmo grupo auth:sanctum das outras rotas de usuário)

Como testar

curl http://localhost:8000/api/user/progress/weekly \
  -H "Authorization: Bearer SEU_TOKEN" \
  -H "Accept: application/json"

Deve devolver um array com 12 objetos, um por semana.
