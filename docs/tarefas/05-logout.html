Logout

O menor arquivo do projeto, mas demonstra algo importante: como destruir uma sessão.

O arquivo

backend/api/auth/logout.php
<?php
require_once __DIR__ . '/../cors.php';

if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
    json_out(['error' => 'Método não permitido'], 405);
    exit;
}

// Limpa todos os dados da sessão
$_SESSION = [];

// Apaga o cookie PHPSESSID no navegador do usuário
if (ini_get('session.use_cookies')) {
    $params = session_get_cookie_params();
    setcookie(session_name(), '', time() - 42000,
        $params['path'], $params['domain'],
        $params['secure'], $params['httponly']
    );
}

// Destrói a sessão no servidor
session_destroy();

json_out(['success' => true, 'message' => 'Logout realizado']);
Por que mais que só session_destroy()? session_destroy() apaga a sessão no servidor, mas o cookie PHPSESSID ainda fica no browser. As três etapas acima garantem uma limpeza completa: esvazia a sessão em memória, invalida o cookie no browser, e apaga no servidor.

Como testar

# Usa o cookie salvo na tarefa anterior
curl -s -b /tmp/cookies.txt -X POST http://localhost:8000/api/auth/logout.php

# Tenta usar o mesmo cookie de novo — deve dar 401
curl -s -b /tmp/cookies.txt http://localhost:8000/api/profile.php
