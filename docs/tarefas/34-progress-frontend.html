Passo a passo

1

Buscar as três fontes de dado

Você tem três rotas pra consumir aqui (tarefas 13, 14 e 15 do backend) — dá pra buscar as três em paralelo com Promise.all, em vez de uma de cada vez:

frontend/app/progress/page.tsx
import { fetchFromApi } from "@/app/_lib/server-api"
import { generateWeeks } from "@/app/_lib/progress" // mantém só o helper de calendário visual

type Stats = { totalPracticed: number; totalCorrect: number; userXp: number }
type WeeklyPoint = { week: string; xp: number; treinos: number }
type CalendarDay = { date: string; level: number }

export default async function ProgressPage() {
    const [stats, weeklyData, calendarData] = await Promise.all([
        fetchFromApi<Stats>("/user/stats"),
        fetchFromApi<WeeklyPoint[]>("/user/progress/weekly"),
        fetchFromApi<CalendarDay[]>("/user/calendar"),
    ])

    const { weeks, currentWeekIdx } = generateWeeks()

    // ... resto da página usa stats, weeklyData e calendarData
    // no lugar de FAKE_STATS / FAKE_WEEKLY_DATA / computeStats(...)
}
Promise.all — buscar em paralelo, não em sequência Se você fizesse await fetchFromApi(...) três vezes seguidas, cada chamada esperaria a anterior terminar antes de começar — desperdiçando tempo. Promise.all([...]) dispara as três requisições ao mesmo tempo e só segue adiante quando todas tiverem respondido. Pra três chamadas independentes (uma não depende do resultado da outra), isso é bem mais rápido.
2

Ajustar o cálculo de "completionRate" e afins

A função computeStats() do mock calculava coisas como completionRate e totalHours a partir de FAKE_STATS. Como a API já devolve totalPracticed/totalCorrect/userXp prontos (lembra da tarefa 13?), você pode manter essa mesma lógica de cálculo derivado, só trocando a entrada — algo como computeStats(stats) em vez de computeStats(FAKE_STATS), se a função aceitar esse formato; ajuste os nomes de campo se precisar.

3

Heatmap de calendário

O componente ConsistencyHeatmap provavelmente espera um formato de dia-a-dia parecido com o que GET /api/user/calendar já devolve ({`{ date, level }`}). Confira a prop que ele recebe e ajuste o nome se for diferente.
