Conectar o progresso

progress/page.tsx já é Server Component. Troque os imports de dados fake pelas chamadas reais:

frontend/app/progress/page.tsx
import { fetchFromApi } from "@/app/_lib/server-api"

type Stats = { totalPracticed: number; totalCorrect: number; userXp: number }
type WeeklyPoint = { week: string; xp: number; treinos: number }
type CalendarDay = { date: string; level: number }

export default async function ProgressPage() {
    const [stats, weeklyData, calendarData] = await Promise.all([
        fetchFromApi<Stats>("/user/stats.php"),
        fetchFromApi<WeeklyPoint[]>("/user/progress-weekly.php"),
        fetchFromApi<CalendarDay[]>("/user/calendar.php"),
    ])
    // Passe stats, weeklyData, calendarData para os componentes
    // no lugar de FAKE_STATS, FAKE_WEEKLY_DATA etc.
}
Promise.all busca as 3 rotas em paralelo — mais rápido que 3 awaits sequenciais.
