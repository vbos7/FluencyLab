Leaderboard (ranking geral)

Agora que ranking_points está sendo populada automaticamente (tarefa 16), é só somar os pontos por usuário e ordenar.

O que você vai aprender

  • Como somar uma coluna de uma tabela relacionada, agrupando por usuário (withSum).

Passo a passo

1

Relacionamento no Model User

Antes de somar, o User precisa "saber" que tem vários RankingPoint:

backend/app/Models/User.php
public function rankingPoints()
{
    return $this->hasMany(RankingPoint::class);
}
2

Controller

docker compose exec backend php artisan make:controller RankingController
backend/app/Http/Controllers/RankingController.php
use App\Models\User;

public function index()
{
    $users = User::withSum('rankingPoints as xp', 'points')
        ->orderByDesc('xp')
        ->limit(30)
        ->get();

    return $users->map(fn ($user) => [
        'id' => $user->id,
        'name' => $user->name,
        'xp' => $user->xp ?? 0,
        'level' => $this->calculateLevel($user->xp ?? 0),
    ]);
}

private function calculateLevel(int $xp): int
{
    // mesma fórmula que já existe no frontend: nível N exige N × 150 de XP acumulado
    $level = 1;
    while ($xp >= $level * 150) {
        $level++;
    }
    return $level;
}
withSum('rankingPoints as xp', 'points') Isso é um atalho do Eloquent pra fazer, em uma única query eficiente, o equivalente a "pra cada usuário, soma a coluna points de todos os ranking_points dele, e chama o resultado de xp". Sem isso, você teria que fazer um loop manual chamando $user->rankingPoints->sum('points') pra cada usuário — funciona, mas dispara uma query por usuário (lento com muitos usuários).
3

Rota

Pode ser pública (ver o ranking não exige estar logado, só interagir com ele):

Route::get('/ranking', [RankingController::class, 'index']);

Como testar

curl http://localhost:8000/api/ranking
