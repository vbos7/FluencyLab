Tarefa 09 Aluno B Extra

Comentários de aula

Pode deixar pra depois — os comentários no frontend são só visuais hoje (não persistem). Pule pra tarefa 10 se quiser ir logo pra prática com IA.

O que fazer (resumo)

  1. Adicionar uma tabela comments ao schema SQL: id, lesson_id (FOREIGN KEY), user_id (FOREIGN KEY), text TEXT, created_at.
  2. Criar api/lessons/comments.php (ou adicionar em api/courses.php com ?lesson_id=).
  3. GET sem sessão: retorna comentários daquela aula.
  4. POST com sessão: insere um comentário, associando ao $_SESSION['user_id'] — nunca deixe o cliente mandar o user_id, sempre pegue da sessão.
INSERT INTO comments (lesson_id, user_id, text)
VALUES (?, $_SESSION['user_id'], ?)
