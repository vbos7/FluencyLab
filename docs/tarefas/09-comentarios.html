Tarefa 09 Pessoa B Extra

Comentários de aula

Pode deixar pra depois Essa tarefa é opcional — hoje os comentários no frontend são só visuais (não persistem). Se o tempo apertar, pule direto pra tarefa 10 e volte aqui depois.

Passo a passo (resumido)

Mesma receita de sempre — migration + model + controller + rota. Únicas novidades:

  • A tabela comments tem lesson_id (igual ao course_id da tarefa 08) e user_id (igual ao que você vai ver na tarefa 12) — porque um comentário pertence tanto a uma aula quanto a um usuário.
  • A rota de criar comentário (POST /api/lessons/{id}/comments) precisa de auth:sanctum — só usuário logado comenta. A de listar (GET) pode ser pública.
$table->foreignId('lesson_id')->constrained()->cascadeOnDelete();
$table->foreignId('user_id')->constrained()->cascadeOnDelete();
$table->text('text');

No Controller, ao criar o comentário, associe o usuário logado automaticamente (não deixe o cliente mandar o user_id — sempre pegue de $request->user()->id, senão alguém poderia comentar fingindo ser outra pessoa):

Comment::create([
    'lesson_id' => $lessonId,
    'user_id' => $request->user()->id,
    'text' => $request->validated()['text'],
]);
