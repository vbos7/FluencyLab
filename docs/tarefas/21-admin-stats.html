Tarefa 21 Pessoa A Extra

Estatísticas do admin

Painel agregando números de todo o sistema (não só do usuário logado, como nas tarefas 13-15). É o primeiro lugar onde o middleware admin que você criou na tarefa 06 entra em ação de verdade.

Passo a passo (resumido)

docker compose exec backend php artisan make:controller AdminController
use App\Models\User;
use App\Models\Phrase;
use App\Models\Attempt;

public function stats()
{
    return response()->json([
        'totalUsers' => User::count(),
        'totalPhrases' => Phrase::count(),
        'activeToday' => Attempt::whereDate('created_at', today())->distinct('user_id')->count('user_id'),
        'totalXP' => Attempt::sum('xp_earned'),
        'newThisMonth' => User::whereMonth('created_at', now()->month)->count(),
        'avgCompletionRate' => Attempt::avg('score') ?? 0,
    ]);
}

Repare que isso é basicamente a mesma técnica das tarefas 13 e 17 (count(), sum(), avg()), só que sem filtrar por user_id — porque agora queremos o total geral, não de uma pessoa só.

Route::middleware(['auth:sanctum', 'admin'])->group(function () {
    Route::get('/admin/stats', [AdminController::class, 'stats']);
});
Se quiser ir além: GET /admin/stats/growth (crescimento de usuários nos últimos 12 meses) e GET /admin/stats/activity (sessões/XP dos últimos 14 dias) seguem o mesmo padrão de agrupamento por período que você já usou na tarefa 14.
